# FiscalCodeSHU

Vue 3 + TypeScript project managed by AXIOM automation platform.

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Type Check

```bash
npm run type-check
```

## Structure

```
├── src/
│   ├── App.vue          # Root component
│   ├── main.ts          # Entry point
│   ├── env.d.ts         # Vite env types
│   └── components/      # Vue components
├── public/              # Static assets
└── index.html           # HTML template
```

**Type:** Vue 3 / Vite / TypeScript
